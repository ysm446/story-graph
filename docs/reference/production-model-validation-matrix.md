## 判定の読み方

- **○ 合格**：検証条件を満たし、この項目で特記する問題は観測しなかった。
- **△ 条件合格・問題あり**：保存結果など既存テストの条件は満たすが、再試行・余分な編集・ガードによる拒否などを観測した。
- **× 不合格**：検証条件を満たさなかった。最終結果が近くても、完全一致や編集回数の条件を満たさなければ不合格とする。
- **— 未検証／未到達**：実施していない、または前段の失敗で到達していない。不合格とは区別する。

各項目は原則1回。途中指示は改善後に各モデル3回、48シーン相談は本文に記した回数を実施した。少数試行であり、成功率やモデル全般の能力順位を表すものではない。

### ハーネスの効果と残課題

- **ハーネスで解消したもの**: 途中指示と取り消しの区別（Qwen 0/3 → 6/6）、適用済み操作の再試行（26B・Qwen の接続変更）、
  相談モードの承認発言への切替案内（26B・12B）、照合の誤検出による正当な編集の拒否（26B・Qwen の資料庫分岐）、
  同一場面の重複挿入（26B）。反復は4回目（読み取り）・3回目（エラー・適用済み）で止まり、16ステップを使い切る回は保護項目のQwenだけになった。
- **モデルの癖として残るもの**: Qwen の保護対象への繰り返しの試行と本文の積み増し（ハーネスは3回目で止めて報告させる）、
  26B の編集前の同じ読み取りの反復（2〜3回。4回目で停止）、Qwen の相談中の読み取り反復（停止後のまとめで案に到達）。
- **少数試行**: 同じ項目でも周によって結果が変わった（26B の基本・作業メモ、Qwen の質問・接続変更）。成功率やモデル順位を示すものではない。
- 未対応: 言い換えの重複追記や依頼にない設定の検出、改善前後の同条件・複数試行の比較。
