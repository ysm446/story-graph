## 判断と次の改善候補

- 26B A4Bは編集ツールを呼び、保存・接続変更・メモ照合まで完了できる。31B専用で動かないという結果ではない。
- 「案を示して確認待ちで終了」は実行モードでも再現した。通常文章だけなら制作終了とする実装との組み合わせであり、能力不足だけに原因を限定できない。
- 中規模以上の作品ではコンテキスト不足を別に確認する。今回の48シーンでは16384は不足、32768で完了した。すべての作品に32768で十分という意味ではない。
- モデル判断の対策候補は、実行依頼に対して変更0件で確認待ちになった場合の扱い、適用済み操作の再試行抑止、意味の重複検出。今回これらの製品修正はしていない。
- 31Bとの比較、Q4版、繰り返し試行による成功率、実アプリUIを含む通し操作は未検証。専用サーバーは検証終了後に停止した。
