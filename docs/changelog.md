# Changelog

## 未リリース

- 2026-07-26 02:40 記憶(memory_add)に**目撃と伝聞**を含めるようにした。共通イベントルール(シーン生成 / イベント抽出で共用)に「行動した本人だけでなく、その場に居合わせて心が動いたキャラにも出す(見た・聞いた・気づいた、も記憶)」「人から聞いた話は誰から聞いたかを含めて、見たことと区別できる書き方にする」「importance の目安(人生を変える 0.8〜1.0 / 当事者の体験 0.5〜0.7 / 目撃・伝聞 0.3〜0.5 / 些細 0.1〜0.2)」を追加。従来は行為者にしか記憶が出ず、居合わせただけのキャラや伝聞が state に残らないため、キャラクターとの会話や POV 清書で本人が「知らない」と答えてしまっていた。12B 実機で、傍観者の目撃記憶(0.5)と伝聞記憶(0.4)が分かれて出ることを確認。

- 2026-07-26 02:20 感情の核(emotional_core)を少し長めに。自動生成の指示を「1行20字前後」→「40字前後(長くなるときは2文まで)」に変更し、スキーマの maxLength を 60 → 160(title は 30 → 40)に緩和した。maxLength は文字列の暴走ループ対策として短く設定していたが、原因が思考モード(全呼び出しで無効化済み)と判明したため。あわせてシーンエディタの Emotional core 欄を input から自動で高さが伸びる textarea に変更(シーン本文と同じ仕組み。折り返しと幅変更にも追従)。

- 2026-07-26 02:00 チャットのメッセージにホバー操作を追加(lm-chat の msg-action-btn を移植)。自分の発言には **✎ 編集 / ⟳ 再生成 / 🗑 削除**、返事には **🗑 削除**(発言は残す)。編集はその場が入力欄になり「送り直す」でその往復以降を作り直す(Escape で取消)。編集・再生成は `POST /chat/send` の新しい `replace_from` で履歴を巻き戻してから送る。削除は `DELETE /chats/{id}/turn/{index}`(`keep_user=true` で返事だけ削除)で、ツール行も往復の一部として一緒に消える。生成中はアイコンを出さない。往復の終わりに保存済み履歴から表示を組み直して位置を揃える。

- 2026-07-26 01:40 チャットの返事の下に生成統計を表示(lm-chat と同じ並び): `⚡ 38.3 tok/sec · 💬 10 tokens · 🕐 0.26s · Finish reason: stop`。ツールを使った返事は `🔧 N ステップ` も付き、トークン数と時間はステップの合計。llama-server の最終チャンクの `timings`(無ければ `usage`)から取得し、取れない項目は省略。統計は assistant メッセージの `meta` として保存するので履歴を読み直しても残る(LLM へ送るメッセージからは除外)。12B 実機で確認済み。
