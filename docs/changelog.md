- 2026-07-27 矢印キーで続けてシーンを移動すると、**インスペクタのタイトル / シーン / Emotional core / Cast / 場所が前のシーンのまま残る**不具合を修正(ユーザー報告)。原因は未保存下書きの一時退避(`beatDraftCache`)の書き込み先の取り違え。シーンが切り替わった直後の 1 レンダーでは `draft` state がまだ前のシーンの値なので、退避用の effect が **前のシーンの内容を移動先のシーンの下書きとして保存**していた。通常は次のレンダーで掃除されるが、掃除が走る前にもう一度移動すると(矢印キーの連打)、通り過ぎたシーンに間違った下書きが残り、次にそのシーンを開いたときに「未保存の下書き」として復元されていた。`draftNodeId` を持たせ、**draft が現在のシーンのものになるまで退避しない**ようにした(`dirty` の判定も同様に抑える)。この 5 項目だけがずれて挿絵やイベントは正しく切り替わるのは、退避の対象がこの 5 項目だったため。

- 2026-07-27 モデル選択バーの**読み込み中の表示を、ノードの LLM 処理中と同じ「時計まわりに光る枠」**にした(ユーザー要望)。従来は `animate-pulse`(全体の明滅)で、ノード側の演出と揃っていなかった。`.node-busy-ring` のはみ出し量・角丸・太さ・グローの強さを CSS 変数(`--sg-ring-inset` / `--sg-ring-corner` / `--sg-ring-width` / `--sg-ring-glow`)に切り出し、ノードカード以外にも付けられるようにした(既定値は従来のノードカード = `rounded-3xl` のままなので見た目は変わらない)。バーは小さいのでリングを 3px → 2px、グローを 14px → 10px に落としている。
